# 可直接複製的 Prompt 範本

以下為本案需求整理後的範本；括號內容請依新案替換。標示「新增建議」的部分並不表示原網站已實作。

## 01｜從需求建立互動網站

```text
請建立一個繁體中文 Three.js 互動網站，用來討論戶外電子看板的設置與安全。
案場：臺北市中正區貴陽街一段 56 號停車場入口。
請以附上的建物全景及出入口照片重建場景。

交付內容：
1. 可旋轉、縮放的 3D 場景與看板位置切換。
2. 駕駛接近和轉入車道時的視角比較。
3. 雨水漏電、絆倒、強風脫落、夜間眩光、開挖下陷及散熱不良的教學動畫。
4. 設計要點、法規適用條件、官方來源及費用拆解。
5. 可使用的網站網址。

請區分照片觀察、模型假設及待現勘項目。
照片無法確認的尺寸不得當成測量結果；危害動畫不得宣稱是實際失效預測。
請沿用目前網站的公開／私人設定；新建網站先採私人設定。
```

## 02｜用照片修正出入口

```text
請依這五張新照片更新既有模型，保留目前建物外觀、網站功能與操作方式。
左右以「站在街道面向入口」為準。

重點修正：
- 左右排風口都是凸出的磚砌低箱體，頂部為平頂蓋。
- 百葉在朝向車道的內側；街側為磚牆與告示。
- 補上靠車道的黑黃防撞角、控制設備、兩側樹穴與入口鋪面。
- 不要將看板、支架或電線擋住百葉及維修空間。

請列出本次修正與仍屬推估的尺寸，提供近看排風口的視角。
```

## 03｜三處看板最終配置

```text
請將既有網站看板配置統一為下列版本：

① 左排風口：位於內側上方；面板沿車道方向，正面朝車道內側。
② 右排風口：位於頂部上方；面板與入口立面平行，正面朝街道。
③ 入口左側第一棵行道樹：在樹穴旁使用獨立支架，預設朝街道；不要固定在樹幹。

左右以站在街道面向入口為準。
保持原有面板尺寸、③位置、建物模型及危害功能。
請同步修改實際 3D 物件、正面法向、可見性計算、位置選單與說明文字。
不要只修改標籤，也不要互換位置編號。
```

## 04｜公平比較駕駛視角

```text
請比較三處候選看板的駕駛可見性。
預設從右側接近；維持相同車位、眼高、視線、面板尺寸與亮度。

功能：
- 左右接近方向切換、播放／暫停、進度滑桿、俯視路徑。
- 「看行進方向」與「轉頭看入口」分開選擇；不要自動瞄準看板。
- 一次顯示一個候選看板；各方案獨立計算，避免候選看板彼此遮擋。
- 保留樹木、排風箱及建物遮擋；提供暫隱樹木的對照。
- 顯示距離、斜視角、角寬及視野內且未遮擋的面板採樣比例。
- 單面看板背面不可顯示可讀內容。

明確註記比例為幾何採樣結果，不是文字辨識率。
```

## 05｜只交換兩處朝向

```text
修正電子看板的位置與朝向：
目前①與入口立面平行、面向街道；②沿車道方向、面向車道內側。

改為：
①左排風口：沿車道方向，面向車道內側。
②右排風口：與入口立面平行，面向街道。

保留：③、預設從右側接近、面板尺寸及其他功能。
驗收：3D 畫面、正反面判斷、可見性數據及所有位置說明一致。
完成後更新既有網站並提供原網址。
```

## 06｜整理成可教學的 GitHub 專案

```text

專案名稱：outdoor-sign-threejs-prompt-lab
可見性：依指定 GitHub 專案目前設定（公開／私人需先確認）
內容：README、本機執行、使用手冊、Prompt 範本、案例演進、技術架構與素材來源。
Prompt 請整理成可直接複製的範本，並註明不是逐字對話。
保留最後確認的三處朝向及預設從右側接近。

不要收錄 Token、密碼、環境變數、無關私人對話、node_modules 或建置輸出。
保留第三方授權，不替照片擅自指定開源授權。若目的地為公開 repository，只上傳程式碼與文件，照片另待授權。
建立獨立副本，不自動改變原網站的部署綁定。
完成後推送並提供 GitHub repository 網址及驗證結果。
```
