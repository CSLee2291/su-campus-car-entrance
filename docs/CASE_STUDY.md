## 最終規格優先

歷史版本曾使用 A／B／C 編號，也曾採用相反的左右看板朝向。現在應以 README 的①②③及 `app/visibility.ts` 的 `SIGN_SITES` 為準，不能直接以歷史截圖作目前驗收標準。

## 當時完成的驗證

- 第 5 版曾以瀏覽器預覽核對三張比較卡、右側接近、排風口近看與五張照片載入。
- 第 6 版完成建置與方向數學檢查：①朝 +X 車道內側、②朝 +Z 街道；單面看板前後視角得到相應結果。
- 雲端預覽曾使用 SVGRenderer 簡化模式；一般支援 WebGL 的裝置使用 WebGLRenderer。未宣稱所有瀏覽器、手機與真實 LED 設備均已驗證。
