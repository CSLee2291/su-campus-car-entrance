# 網站使用說明

## 駕駛視角比較

1. 開啟首頁的「駕駛視角比較」。預設從右側接近，位於轉入中的 80% 進度。
2. 選擇①左排風口、②右排風口或③第一行道樹。一次顯示一個候選方案，避免其他候選看板造成額外遮擋。
3. 使用「遠處接近／轉彎前／轉入中／入口前」或滑桿固定同一車位，再切換方案。
4. 播放完整路徑，觀察看板何時進入或離開視野。此播放不是等速車輛動力學模擬。
5. 「看行進方向」與「轉頭看入口」代表不同視線，請分開比較。
6. 可切換左右來車、眼高或暫隱樹木。「暫隱樹木」僅為遮擋對照，不是移樹建議。
7. 「俯視路徑」同時呈現三處位置；下方數字仍由駕駛眼睛的位置計算。

## 四個數字怎麼看

| 指標 | 代表意義 | 不能直接推論 |
|---|---|---|
| 視野內且未遮擋 | 45 個正面採樣點中，位於畫面範圍且射線未受遮擋的比例 | 駕駛實際辨識率 |
| 眼睛至面板中心 | 模型中的空間距離 | 真實測距結果 |
| 面板斜視角 | 0° 正視、90° 側視、大於 90° 為背面 | LED 廠商的保證可讀角度 |
| 面板水平角寬 | 面板左右邊缘在視線中形成的夾角 | 字體已足夠大、必然能讀完 |

單面看板朝向背面時，可見內容比例為 0%。即使比例是 100%，若距離遠或接近側視，文字仍可能很難辨識。

## 互動模擬

- 選擇危害情境，切換「加入改善措施」比較示意動畫。
- 調整風速、雨量、相對亮度及面板尺寸。
- 選擇套用危害的看板位置；其他位置作配置參考。
- 使用「車道入口／建築全貌／俯視配置／排風口近看」，或拖曳旋轉場景。
- 風力數字是固定假設下的簡化計算，不是法定耐風設計或支架強度驗證。

## 其他分頁

- **案場觀察**：對照照片，確認排風百葉朝向、樹穴及看板方位。
- **設計要點**：發包與驗收要確認的條件。
- **法規與許可**：依用途及設置條件判斷適用範圍，附官方來源。
- **費用拆解**：輸入廠商逐項報價。空白不是 0 元；「示範拆帳」不是行情估價。

輸入與比較狀態目前沒有雲端儲存，重新整理會回到預設值。若修正後仍見舊版，請先重新整理網站。
